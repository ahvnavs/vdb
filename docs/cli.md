# CLI reference

The CLI prints machine-readable operation reports as JSON. Human diagnostics
and structured tracing go to standard error. Protected plaintext is printed
only by an explicit `get` command and is never written to a temporary file by
VDB.

## Exit status

These statuses are stable for the current major CLI series:

- `0`: command completed successfully;
- `1`: operational failure, including invalid data, conflicts, I/O, corruption,
  unsupported database formats, or failed verification;
- `2`: command-line syntax or argument error generated by Clap.

Scripts must inspect JSON reports rather than parse diagnostic text. Future
major versions may introduce more specific nonzero statuses, but will not
change the meaning of 0 or 2 within the same major version.

## Commands

```text
vdb keygen --output DATABASE_KEY_FILE
vdb writer-keygen --output IDENTITY_FILE
vdb put --db DATABASE --key-file DATABASE_KEY_FILE COLLECTION ID JSON_FILE
vdb get --db DATABASE --key-file DATABASE_KEY_FILE COLLECTION ID
vdb verify --db DATABASE
vdb backup --db DATABASE --output BACKUP
vdb backup-verify --backup BACKUP
vdb restore --backup BACKUP --db DATABASE
vdb restore-verify --db DATABASE
vdb snapshot --db DATABASE --output BACKUP
vdb inspect --db DATABASE
vdb status --db DATABASE
vdb compact --db DATABASE
vdb serve --db DATABASE --bind ADDRESS --tls-cert CERT --tls-key KEY --auth-config JSON
```

Secret-output commands use create-new semantics and do not overwrite an
existing path. On Unix the initial mode is 0600. Database and backup creation
also reject unsafe overwrite where documented. `compact` requires exclusive
offline access.

`serve` requires authorization configuration format 1. Unknown configuration
fields, duplicate principals, invalid public keys, empty permissions, and an
unsupported format version are rejected. Network defaults and REST behavior are
defined in `docs/protocol.md`.

There is intentionally no `sync` command yet. Replication is an embedded API;
claiming CLI/network synchronization before authenticated transport and durable
identity custody exist would be misleading.
